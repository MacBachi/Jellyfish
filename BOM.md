# Bill of materials

Parts for one jellyfish, as used by the original Sheffield-by-the-Sea build. Prices are the original
project's reference prices in GBP from 2026 (partly leftover stock) and will not match retail; treat them
as a rough scale. The [Pimoroni write-up](https://learn.pimoroni.com/article/building-sound-reactive-jellyfish)
describes the exact products and the sewing.

| Part | Qty | Notes | Reference price |
|---|---|---|---|
| Raspberry Pi Pico 2 W | 1 | RP2350 with WLAN; the board solders it flat, so the version without headers | £6.60 |
| WS2812B strip, 144 LEDs/m | 96 LEDs (0.67 m) | the ring around the bell | £3.88 |
| WS2812B "fairy wire" string, 10 LEDs/m | 48 LEDs | four tentacles of 12; the firmware drives up to seven tentacles of 16 | £2.70 |
| INMP441 I2S microphone breakout | 1 | 6-pin module, fits the 2×3 footprint on the board | £0.98 |
| Tactile push button 6×6×4.3 mm | 2 | previous / next mode | £0.06 |
| LED noodles, 300 mm, 3 V | 4 | the four loops, PWM-driven | £4.47 |
| Jellyboard PCB | 1 | 2-layer, production files in `pcb/production/` | |
| Pin header 2.54 mm, 1×40 | 1 strip | cut into 8×3, 4×2 and 1×4 | |
| Resistor 0207, 22–47 Ω | 4 | series resistors for the noodles (the schematic gives no value) | |
| 5 V power supply, 2.4 A or more, micro-USB | 1 | see the power notes in the README | |
